# DepenseMoi-Backend
DepenseMoi-Backend is a RESTful API service that powers the personal expense management application. It handles user authentication, expense tracking, budget management, and provides statistical analysis of spending patterns.

# Features
User authentication and authorization
Expense tracking and categorization
Budget management and monitoring
Income tracking
Statistical analysis and reporting
Secure API endpoints

# Tech Stack
Spring Boot
Spring Security
Spring Data JPA
MySQL Database
Maven
JWT Authentication

#Security
JWT-based authentication
Password encryption
Role-based access control
